# «Красноярск пешком» — спецификация для Claude Code

Положи файл в корень пустого репозитория как `SPEC.md`. Первый промпт — в конце.

## 1. Что строим

Браузерная 3D-игра в стилистике Roblox: квадратный человечек ходит по стилизованному Красноярску и находит достопримечательности. За каждую — штамп в «паспорте путешественника» и короткий факт вслух. Игрок — первоклассник: никакого текста, без которого нельзя играть; ничего, что можно проиграть.

Работает на телефоне и на компьютере. Публикуется на GitHub Pages.

## 2. Стек

Vite + TypeScript + three.js (актуальная версия). Без физического движка: свои коллизии «капсула против коробок». Без загрузки 3D-моделей: **вся геометрия — кодом из примитивов** (коробки, цилиндры, конусы). Блочный стиль делает это реалистичным и даёт единый вид.

Dev-зависимости: Playwright (для скриншотов, см. раздел 4), Vitest.

```
src/
  main.ts
  player/        controller.ts  avatar.ts  camera.ts  input.ts (клавиатура + тач-джойстик)
  world/
    world.ts     terrain.ts  river.ts  city-blocks.ts
    landmarks/   chapel.ts  bridge.ts  clocktower.ts  ...   # одна достопримечательность = один файл
    landmarks.json   # id, название, позиция, поворот, радиус зоны, текст факта
  game/          passport.ts  zones.ts  save.ts  speech.ts
  ui/            hud.ts  passport-screen.ts  minimap.ts
viewer.html      # страница-витрина одной достопримечательности
scripts/shot.ts  # скриншоты через Playwright
refs/            # фото-референсы и рисунки, кладёт человек
```

## 3. Мир

Карта **условная, не в масштабе**: город сжат так, чтобы от одной точки до другой было 20–40 секунд ходьбы. Сохраняем только взаимное расположение.

- Енисей течёт через середину карты, вода — плоскость с простой анимацией.
- Левый берег: Стрелка → Театр оперы и балета → башня с часами («Биг-Бен») → часовня Параскевы Пятницы на горе (единственный заметный подъём).
- Коммунальный мост соединяет берега, по нему можно пройти. Рядом — пароход «Святитель Николай».
- Остров с колесом обозрения.
- Правый берег: фуникулёр и вдалеке Столбы — крупные скалы, на одну можно забраться по тропе.
- Между достопримечательностями — типовые блочные дома, деревья, фонари. Через `InstancedMesh`.

Каждая достопримечательность — функция `build(): THREE.Group`, собранная из примитивов, 30–150 мешей, узнаваемая по силуэту и 2–3 характерным деталям. Фотореализм не нужен.

## 4. Главное: цикл обратной связи по картинке

Claude Code не видит результат. Без этого пункта достопримечательности выйдут неузнаваемыми.

- `viewer.html?id=chapel` показывает одну достопримечательность на нейтральном фоне.
- `npm run shot -- chapel` через Playwright снимает её с 4 ракурсов в `shots/chapel-{front,side,back,top}.png`.
- Порядок работы над каждой: посмотреть референсы в `refs/chapel/` → написать геометрию → снять скриншоты → **открыть PNG и сравнить с референсом** → поправить. Минимум две итерации.
- Такой же скрипт для общего вида мира: `npm run shot -- world`.

## 5. Игрок и управление

- Аватар: блочный человечек (голова, тело, руки, ноги), простая анимация ходьбы качанием конечностей. Цвет одежды и шапка выбираются на старте.
- Вид от третьего лица, камера плавно следует, не проваливается в здания.
- Компьютер: WASD/стрелки, пробел — прыжок, мышь — поворот камеры.
- Телефон: джойстик слева, кнопка прыжка справа, поворот камеры свайпом по правой половине. Крупные элементы.
- Упасть в воду нельзя проиграть: человечек возвращается на берег.

## 6. Игровой слой

- У каждой достопримечательности зона. Вошёл — звук, конфетти, штамп в паспорт, факт вслух через `speechSynthesis` (ru-RU), плюс текст крупно.
- Паспорт — экран с сеткой штампов: найденные цветные, ненайденные силуэтом.
- Мини-карта с отметками найденного.
- Пасхалка: у часовни лежит большая десятирублёвка.
- Прогресс — в `localStorage`, с try/catch.
- Факты — 1–2 коротких предложения, язык первоклассника. Тексты пишет и проверяет человек.

## 7. Производительность

Цель — 30+ fps на среднем телефоне. До 150 draw calls в кадре, `InstancedMesh` для повторяющегося, один направленный свет, тени выключены или одна дешёвая карта, без постобработки. Материалы — `MeshLambertMaterial`, плоские цвета из общей палитры в `palette.ts`.

## 8. Этапы (каждый — отдельная сессия и коммит)

1. Каркас: Vite, сцена, земля, река, человечек ходит и прыгает, камера, тач-управление. Деплой на GitHub Pages сразу.
2. Витрина + скрипт скриншотов + первая достопримечательность (часовня) полным циклом из раздела 4.
3. Зоны, паспорт, звук, речь, сохранение — на одной часовне.
4. Дальше по одной достопримечательности за сессию: мост → башня с часами → Оперный → пароход → колесо → Столбы с фуникулёром.
5. Город-заполнитель: дома, деревья, фонари, коллизии.
6. Мини-карта, выбор внешности, полировка под телефон.
7. По желанию: машинки, голуби, день/ночь, монетки.

**Правило очереди:** какую достопримечательность делать следующей, решает Тёма. Его рисунок кладётся в `refs/<id>/` рядом с фотографиями.

## 9. Правила для Claude Code (перенести в CLAUDE.md)

- Геометрия только из примитивов, цвета только из `palette.ts`.
- Одна достопримечательность — один файл, один экспорт `build()`.
- После любого изменения геометрии — скриншоты и просмотр PNG. Не заявлять «готово» без этого.
- Не трогать управление и камеру в сессиях про достопримечательности.
- Сначала план, потом код. Один этап — одна сессия, в конце коммит.
